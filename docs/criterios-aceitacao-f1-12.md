O relógio de referência dos cenários puros/SQL é 2030-01-15T10:00:00Z, injectado no servidor de teste. No browser usar fixtures relativas a um instante capturado ou um relógio de teste restrito ao laboratório. Não alterar a hora global do Windows ou WordPress de outros módulos. LAB-A/B activas, contas Active e sessões da geração corrente. Criar controlos positivos antes de cada recusa, para que uma configuração errada não simule segurança.

Os restantes recebem apenas concessões explicitamente descritas e leitura separada quando necessária. O administrador técnico é controlo negativo para negócio e actor apenas da instalação CLI. Um editor de notícias sem concessão F1-12 é outro controlo negativo.

## Conjunto fictício de conteúdos

Usar títulos inequívocos: Comunicado de ensaio A, Comunicado institucional de ensaio, Evento de ensaio A e Evento institucional de ensaio. Sem nomes de pessoas reais, assinaturas, documentos recebidos ou ligações de reunião activas. Uma ligação de exemplo é https://example.invalid/reuniao-f112 e não deve ser aberta pelo teste. Para casuística temporal criar eventos em curso, futuros, passados, de dia inteiro, multi-dia e cancelados em torno do relógio definido. Reiniciar só os recursos exclusivos de cada teste, nunca o WordPress normal.

Dados de autorização não são inferidos do autor do conteúdo. Usar outra conta para recusa transversal de autoria, outro âmbito para recusa territorial e concessão parcial para provar que a cobertura não se agrega. Incluir uma pessoa com concessão de gestão mas sem leitura Employee para verificar a separação de pacotes existente.

A aceitação Playwright exige WordPress e base reais no laboratório. Unitários, rendering estático, CI development e runtime PHP sem WordPress não substituem esse percurso. Diferenciar zoom nativo de CSS a 200% e valor nominal de valor efectivo. Fechar apenas contextos de teste próprios.

Uma condição de segurança falhada ou não executada impede declarar o módulo aceite. Resultados institucionais e de infraestrutura continuam pendentes mesmo depois do laboratório passar.
